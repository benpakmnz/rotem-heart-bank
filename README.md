# 💖 אוצר הלבבות של רותם - משחק יום הולדת לטלוויזיה

משחק משפחתי אינטראקטיבי ליום הולדת 7: **הטלוויזיה** מציגה את המשחק, ו**כל אורח משחק מהטלפון שלו** - בלי להתקין שום אפליקציה, רק סורקים קוד QR.
כל לחיצה בטלפון מגיעה בזמן אמת לטלוויזיה וממלאת את "האוצר של רותם" בלבבות, עד שהוא מתמלא ב-100% אהבה - ואז זיקוקים, שיר יום הולדת והכרזה על המנצח/ת.

| 📱 טלפונים | סורקים את ה-QR שעל המסך (או נכנסים ל-`/join` ומקלידים את הקוד בן 4 הספרות) |

## 🔥 Firebase - כבר מחובר

המשחק משתמש ב-**Firebase Realtime Database** כדי לסנכרן את הטלפונים עם הטלוויזיה, והוא כבר מחובר למסד של הפרויקט `rotem-heart-bank`:
`https://rotem-heart-bank-default-rtdb.europe-west1.firebasedatabase.app` (הכתובת נמצאת ב-[`src/party/net/firebaseConfig.js`](src/party/net/firebaseConfig.js)).

**הדבר היחיד שצריך לוודא - שכללי המשחק פורסמו:**
ב-[console.firebase.google.com](https://console.firebase.google.com) פותחים את הפרויקט `rotem-heart-bank` ← **Realtime Database** ← הלשונית **Rules**, מוחקים את מה שיש, מדביקים את כל התוכן של הקובץ [`database.rules.json`](database.rules.json) ולוחצים **Publish**.
הכללים מאפשרים לקרוא ולכתוב רק בתוך `rooms/<קוד בן 4 ספרות>`, ואי אפשר לראות רשימה של כל המשחקים. בלי זה הטלוויזיה תציג **"Firebase חוסם את המשחק"**.

אין צורך ב-API key או בהתחברות. הטלפונים יכולים להצטרף מכל רשת (WiFi או סלולרי), והתוכנית החינמית של Firebase מספיקה בקלות (עד 100 חיבורים בו-זמנית).

<details>
<summary>מעבר למסד Firebase אחר</summary>

1. ב-[console.firebase.google.com](https://console.firebase.google.com) צרו פרויקט ← **Realtime Database** ← **Create Database** (מיקום **europe-west1**, מצב **Start in locked mode**).
2. פרסמו את הכללים כמו למעלה.
3. העתיקו את כתובת המסד מראש הלשונית **Data** ושימו אותה ב-`src/party/net/firebaseConfig.js`,
   או במשתנה הסביבה `REACT_APP_FIREBASE_DATABASE_URL` (ב-Vercel: **Settings ← Environment Variables** ואז **Redeploy**, כי הכתובת נכנסת לקוד בזמן הבנייה).

</details>

## ⚡ ניסיון על מחשב אחד (מצב הדגמה)

מוסיפים `?local=1` לכתובת של מסך הטלוויזיה, למשל `https://<האתר-שלכם>/?local=1`
(או במחשב של מפתח: `npm install`, `npm start` ואז `http://localhost:3000/?local=1`).
יופיע פס צהוב **"מצב הדגמה מקומי"** עם כפתור **"➕ פתיחת שחקן לניסיון"** - כל לחיצה פותחת חלון של "טלפון" נוסף, ואפשר לשחק את כל המשחק על מחשב אחד.

> במצב הזה טלפונים אמיתיים **לא** יכולים להתחבר. בלי `?local=1` המשחק מתחבר ל-Firebase והטלפונים מצטרפים עם ה-QR.

## 📺 איך פותחים את המשחק בטלוויזיה

| דרך | איך |
| --- | --- |
| **מחשב נייד + כבל HDMI** (הכי אמין) | פותחים את הקישור ב-Chrome ולוחצים **F** למסך מלא. העכבר והמקלדת של המחשב הם "השלט". |
| **טלפון + שיקוף מסך** | הטלפון מריץ את מסך הטלוויזיה ומשקף אותו לטלוויזיה - ראו למטה. |

### 📱 הטלפון כמסך הטלוויזיה (שיקוף מסך)

1. פותחים את הקישור בטלפון **ומסובבים אותו לרוחב** (אם הוא נשאר לאורך, המשחק יבקש לסובב).
2. **כל המסך בלי שורת הכתובת:** באייפון - בספארי: שיתוף ← **"הוספה למסך הבית"**, ופותחים את המשחק מהאייקון החדש. באנדרואיד - בתפריט ☰ של המשחק ← **"מסך מלא"**.
3. **משקפים לטלוויזיה:**
   - **אייפון:** מרכז הבקרה ← **"שיקוף מסך"** ← בוחרים את טלוויזיית ה-LG (AirPlay).
   - **אנדרואיד:** בהגדרות המהירות ← **Smart View** / **Screen Cast** / **"שיתוף מסך"** ← בוחרים את ה-LG (בטלוויזיה נפתחת אפליקציית Screen Share).
4. 🔕 הפעילו **"נא לא להפריע"** בטלפון - אחרת כל הודעה שתגיע תופיע בגדול על הטלוויזיה.
5. חברו את הטלפון למטען, והגבירו את עוצמת הטלוויזיה (הצלילים עוברים דרך השיקוף).
6. הטלפון הזה "מפעיל" את המשחק - מי שמחזיק אותו ורוצה גם לשחק, מצטרף מטלפון אחר.

## 🎈 שומר מסך (עד שמתחילים)

מסך חגיגי לטלוויזיה עד שהמשחק מתחיל: רותם עם הכתר, "רותם בת 7! יום הולדת שמח!" וברכות שמתחלפות, עם דגלונים, בלונים, לבבות וקונפטי. **אין בו קוד משחק, QR או פרטים על המשחק.**

- **פותחים אותו:** מוסיפים `/saver` לכתובת של המשחק (`https://<האתר-שלכם>/saver`), או מתוך המשחק: תפריט ☰ ← **"שומר מסך"** (או הקישור 🎈 במסך הפתיחה).
- **עוברים למשחק:** לחיצה בכל מקום על המסך, או **Enter** / **רווח** - מסך הפתיחה עם ה-QR מופיע מיד. הלחיצה הזו לא מתחילה את המשחק.
- **F** - מסך מלא. הזזת העכבר מציגה לכמה שניות שני כפתורים בפינה ("מסך מלא", "מעבר למשחק"); כשהעכבר לא זז, הסמן נעלם מהמסך.
- המשחק כבר פתוח מאחורי שומר המסך, כך שהקוד לא משתנה. אם מנהל/ת המשחק מתחיל/ה את המשחק מהטלפון, שומר המסך יורד לבד.
- המסך לא נכבה כל עוד שומר המסך פתוח. במצב **אפקטים חסכוניים** (טלוויזיה, שיקוף מסך) זזים רק דברים קטנים - נצנוצים וקצת קונפטי - כדי שהשיקוף לא יקרטע.

## 📱 מנהל/ת המשחק - שליטה מהטלפון

1. בטלוויזיה: תפריט ☰ ← **"שליטה מהטלפון (מנהל/ת)"** (או הקישור במסך הפתיחה).
2. סורקים את ה-QR עם הטלפון של מנהל/ת המשחק - נכנסים אוטומטית. (אפשר גם להיכנס ל-`/admin` ולהקליד את קוד המשחק ואת קוד המנהל.)
3. מהטלפון אפשר:
   - **לקדם את המשחק** - אותם כפתורים שיש בטלוויזיה ("מתחילים", "לשאלה הבאה", "הפעלת השעון"...), כך שלא צריך את השלט.
   - **ציידי הלבבות:** לוחצים על לב ← בוחרים מי מצא אותו. טעיתם? בוחרים מישהו אחר או "עוד לא נמצא" - הניקוד מתעדכן.

4. **קוד המנהל** (4 ספרות) מופיע בחלון של ה-QR ואפשר לשנות אותו בעריכת התוכן ← כללי. הוא לא מופיע לאורחים.

> גם בלי טלפון מנהל אפשר לנהל הכל מהטלוויזיה: לחיצה על לב בלוח "ציידי הלבבות" פותחת בחירה של מי מצא.

## ✏️ מה אפשר לערוך (⚙️ עריכת תוכן)

- **כללי:** שם בעל/ת השמחה, גיל, יעד האוצר (0 = אוטומטי), קוד מנהל, ואילו שלבים משחקים.
- **ציידי הלבבות:** כמה לבבות מכל צבע ומה כל אחד שווה, וזמן לחיפוש (0 = בלי שעון).
- **שאלות טריוויה:** שאלה, 4 תשובות וסימון התשובה הנכונה. אפשר להוסיף, לשנות סדר ולבחור אילו שאלות **בחידון** - שאלה בלי הסימון נשארת במאגר ולא נשאלת. השאלות המובנות לא נמחקות, רק יוצאות מהחידון; שאלות שהוספתם בעצמכם אפשר למחוק.
- **מושגים לפנטומימה:** אחד בכל שורה (המציג יכול להחליף מושג עד פעמיים).
- **מילים לפיצוח:** מילה (אפשר גם שתיים, כמו "מזל טוב") + רמז. גם כאן בוחרים אילו מילים **במשחק**, והשאר נשמרות במאגר.
- **הצעות לברכות:** מילים שמופיעות ככפתורים בטלפון, לילדים שעוד לא כותבים מהר.
- **זמנים:** משך הלחיצה, זמן לענות, מספר סיבובי פנטומימה ועוד.

תוכן ברירת המחדל נמצא ב-`src/party/config/content.js`.

**התמונה של רותם** (בלב הזהב שבפתיחה, בטלפונים ובגמר) היא הקובץ [`public/rotem.png`](public/rotem.png): ציור על רקע שקוף, ברוחב הלב, כשהכתר בולט מעליו. כדי להחליף - שומרים קובץ אחר באותו שם ובאותן מידות (510x600).

**מוזיקה:** לכל חלק במשחק יש לופ מקורי משלו (לובי, הסבר השלב, כל אחד מ-6 השלבים, סוף שלב ו"יום הולדת שמח" בגמר). היא מנוגנת רק בטלוויזיה, ואפשר לכבות אותה בתפריט ☰ בלי לכבות את אפקטי הקול. המנגינות נמצאות ב-`src/party/audio/tracks.js`.

## 👩‍💻 למפתחים

```
src/party/
  engine/        מנוע המשחק (reducer טהור) + טסטים - הטלוויזיה היא מקור האמת
  net/           סנכרון: Firebase Realtime Database / מצב מקומי (BroadcastChannel)
  host/          מסכי הטלוויזיה, עורך התוכן, צלילים ואפקטים
  player/        מסכי הטלפון
  lib/           ניקוד, ענן מילים בצורת לב, טקסט עברי
  config/        שלבים, ניקוד, זמנים, תוכן ברירת מחדל, דמויות
```

- טסטים: `npm test`
- `npm start` מתחבר למסד האמיתי. כדי לפתח בלי לגעת בו: `?local=1` בכתובת (מצב הדגמה מקומי), או אמולטור Firebase מקומי עם `REACT_APP_FIREBASE_EMULATOR_HOST=127.0.0.1:9000` בקובץ `.env.local`.
- מנהל/ת המשחק שולחים פקודות ל-`rooms/<קוד>/admin/cmd` עם קוד המנהל, והטלוויזיה מבצעת רק פקודות עם הקוד הנכון ועונה ב-`admin/ack` (`src/party/host/useAdminBridge.js`, `src/party/admin/`).
- כל משחק נשמר תחת `rooms/<קוד>` ב-Firebase. אפשר למחוק משחקים ישנים מה-Console מדי פעם (לא חובה).
